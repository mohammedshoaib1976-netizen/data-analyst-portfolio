# Excel Projects

This folder contains data analysis and automation projects built in Microsoft Excel, showcasing skills in formulas, pivot tables, live dashboards, and data tracking systems.

## 📁 1. Attendance Tracker
**File:** `1_Attendance_Tracker.xlsx`
- **Description:** Tracks daily employee attendance (check-in/check-out times, status) across departments for a full month.
- **Structure:** Raw attendance log, an auto-generated employee summary, and a visual dashboard.
- **Key Skills Used:** Data logging, summary formulas, attendance dashboard design

## 📁 2. Salary Calculator
**File:** `2_Salary_Calculator.xlsx`
- **Description:** Automated monthly salary calculator — enter employee name, department, basic salary, and bonus eligibility, and net payout calculates automatically.
- **Structure:** Editable assumptions sheet, salary calculation sheet, and a department-wise payout dashboard (headcount, gross, net, average salary).
- **Key Skills Used:** Dynamic formulas, conditional logic, payroll dashboard design

## 📁 3. Expense Tracker
**File:** `3_Expense_Tracker.xlsx`
- **Description:** Personal expense tracker that logs transactions by category and compares actual spend against a monthly budget.
- **Structure:** Transaction log, editable budget-by-category sheet, monthly summary (actual vs. budget), and a spend dashboard.
- **Key Skills Used:** Budget vs. actual analysis, live data linking, category-wise reporting

## 📁 4. Sales Dashboard
**File:** `4_Sales_Dashboard.xlsx`
- **Description:** Sales performance dashboard covering Jan–Jun 2026, built from raw sales transaction data.
- **Structure:** Raw sales data sheet feeding into a dynamic performance dashboard.
- **Key Skills Used:** Data aggregation, KPI dashboard design, trend visualization
